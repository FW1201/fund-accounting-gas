# 基金帳務管理系統：需求與開發計畫

## 目標與使用情境

提供小型團體或基金管理者一套可自行部署的 Google Apps Script 帳務系統。兩位管理人以系統帳號登入，交易存於部署者擁有的 Google 試算表。成員透過管理人提供的報表了解收支。本文件使用虛構、通用情境，不含任何特定團體、地址、姓名、原始會議紀錄、真實交易或部署資訊。

## 資料結構

交易記錄唯一 ID、收入或支出、國曆日期、農曆顯示值、以整數分為單位的金額、分類、明細、備註、狀態、帳戶、基金、憑證編號與建立／更新時間。更正和作廢記錄原因、操作人、時間及前後內容。幣別為新臺幣，時區為 Asia/Taipei。金額須大於零；不能用浮點數直接儲存。

支出分類：活動物資、關懷與協助、禮品、餐飲、補貼、其他。收入分類：成員繳款、捐款、活動收入、利息／回饋、其他收入。使用者在下拉清單中選擇分類；舊帳若使用不同分類碼，匯入前須先做對照。

## 操作流程

1. 管理人登入後查看現有餘額、期間收入／支出、月度趨勢、分類圖表和最近交易。
2. 新增收支時填寫日期、金額、分類、明細、帳戶與基金；支出可附憑證並由另一位管理人覆核。
3. 依日期、類型、分類與關鍵字查詢；更正或作廢必填原因並留下操作紀錄。
4. 匯入 CSV 或 Google 試算表時，先驗證格式、重複與核定期末餘額，再整批寫入。
5. 月底核對各帳戶實際餘額、處理待覆核交易、結帳、產生 A4 報表及下載獨立備份。

## 介面與列印

採可愛親切而清楚的基金帳本風格，以暖色卡片、柔和對比和明顯的收入／支出標籤呈現資訊。手機使用單欄表單、足夠大的點擊區與卡片式交易列；桌面使用完整表格。相鄰操作按鈕使用明確的群組間距。儀表板圖表須同時顯示金額和百分比，無資料時顯示空狀態。A4 直式列印只保留報表內容，跨頁表頭重複且交易列不截斷。

## 權限、驗收與維運

主管理人可管控帳號、基金、預算、結帳與備份還原；共同管理人可記帳、覆核、匯入、對帳與檢視報表。支出不得由提交者自行覆核。每個讀寫 RPC 在伺服器端驗證登入 session。密碼由部署者在 Script Properties 設定，公開程式碼不含密碼或固定雜湊。

驗收包含：加總與原始帳本一致；跨月、跨年和農曆日期正確；收入不列入支出圖表；更正、作廢後餘額、報表與操作紀錄一致；錯誤或重複匯入不得部分寫入；未登入者不可讀取資料；手機與桌面按鈕不擁擠；多頁 A4 報表可閱讀；每日備份可驗證並還原。正式上線前用虛構資料完成流程演練，再以實際舊帳核對。
