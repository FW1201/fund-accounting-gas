# 基金帳務管理系統

這是一套放在**自己的 Google 帳號**裡使用的基金帳本。收支資料會存進你自己的 Google 試算表；網站可在手機與電腦使用。你可以自己複製貼上安裝，也可以請熟悉電腦操作的 Agent 幫你把程式推送到新建的 Apps Script 專案。

> 這個 GitHub 倉庫只有程式與虛構範例，沒有任何人的帳本、密碼或現成的管理帳號密碼。安裝時請自己設定密碼。

## 可以做什麼？

- 記錄收入、支出、分類、日期、對象、備註與憑證；查看餘額和圖表。
- 用日期、分類或關鍵字找紀錄；更正、作廢會留下原因與操作紀錄。
- 讓兩位管理人分工：一人登錄支出，另一人覆核。
- 管理現金／銀行帳戶、基金用途、成員繳款、預算和月底對帳。
- 下載儀表板資料、列印 A4 報表、匯入舊帳並建立每日備份。

支出分類：活動物資、關懷與協助、禮品、餐飲、補貼、其他。收入分類：成員繳款、捐款、活動收入、利息／回饋、其他收入。

操作示意與日常記帳步驟請看 [圖解系統使用手冊](docs/系統使用手冊.md)。本系統由**數位敘事力期刊開源提供應用**。

## 安裝前先選一條路

| 方式 | 適合誰 | 你需要準備什麼 |
| --- | --- | --- |
| **A. 手動複製貼上** | 不想安裝任何電腦工具 | Google 帳號；照著畫面貼上 3 個檔案 |
| **B. 請 Agent 安裝** | 有能操作終端機與瀏覽器的 AI Agent | Google 帳號；建立空白專案、親自完成 Google 授權 |

兩條路最後都要做下方的「共同設定」；**只需選一條安裝路線**。第一次安裝請建立全新的 Apps Script 專案，不要把這份公開版直接覆蓋到已有帳本的專案，因為舊版分類碼可能不同。

### A. 手動複製貼上：不用終端機

1. 在本頁按綠色 **Code → Download ZIP**，下載並解壓縮。打開其中的 `install` 資料夾，會看到 `Code.gs`、`Index.html`、`appsscript.json`。這三個檔案已經整理好，**不用再自己組合程式碼**。
2. 用**自己的 Google 帳號**到 [Apps Script](https://script.google.com/home) 按「新增專案」，將專案命名為「基金帳務管理系統」。
3. 點左邊預設的 `程式碼.gs`（英文介面可能叫 `Code.gs`），刪除裡面的範例內容。用文字編輯器打開剛下載的 `install/Code.gs`，**全選、複製、貼上**到程式編輯區。這個檔案較長，請等貼上完成再進下一步。
4. 在左邊「檔案」旁按 **＋ → HTML**，名稱輸入 `Index`（不要再加 `.html`）。用同樣方式把 `install/Index.html` 的**全部內容**貼進去。
5. 點左邊齒輪「專案設定」，勾選「在編輯器中顯示 `appsscript.json` 資訊清單檔案」。回到檔案清單，打開 `appsscript.json`，以 `install/appsscript.json` 的**全部內容**取代原內容。儲存專案。
6. 繼續做下方「共同設定」。**不用在編輯器按執行 `myFunction` 或 `login`**；登入是在部署後的網站完成。

### B. 請 Agent 安裝 Clasp 並推送

1. 用**自己的 Google 帳號**到 [Apps Script](https://script.google.com/home) 建立一個**新的空白專案**，命名「基金帳務管理系統」。到該專案的「專案設定」複製 **指令碼 ID（Script ID）**，或複製專案網址。
2. 到 [Apps Script 使用者設定](https://script.google.com/home/usersettings) 開啟 **Apps Script API**。這是讓 Clasp 能把程式送進你專案的設定。
3. 把下面這段任務文字交給 Agent，並提供**你新建的專案網址或 Script ID**。Agent 需要 Google 授權時，請你親自在 Google 頁面核對帳號與權限並完成授權；不要把密碼、授權碼或回呼網址貼給 Agent。

> 請從 `https://github.com/FW1201/fund-accounting-gas` 下載或複製公開程式到一個**新的空資料夾**。確認使用的是我提供的**新建 Apps Script 專案網址／Script ID**，不要連到其他既有專案。若電腦尚無 Node.js 20 以上，請從官方來源安裝；在新資料夾執行 `npm ci`、`npm run check`。安裝 Clasp（此專案已列為開發套件），以 `npm exec -- clasp login` 讓我親自完成 Google 授權。接著執行 `npm run clasp:link -- <我的專案網址或 Script ID>`，核對 `.clasp.json` 的 `scriptId` 確實是我的新專案，再執行 `npm exec -- clasp push -f`。推送後請到 Apps Script 編輯器讀回，確認有 `Code.gs`、`Index.html`、`appsscript.json`，並回報測試與推送結果。請勿代我建立或保存帳本密碼、上傳任何舊帳，也不要覆寫其他 Apps Script 專案。

4. Agent 回報三個檔案已出現在**你的** Apps Script 專案後，繼續做下方「共同設定」。程式推送成功並不等於網站已部署。

## 共同設定：兩條路都要做

### 1. 設定兩組自己的密碼

在**你的** Apps Script 專案，按左邊齒輪「專案設定」，找到「指令碼屬性（Script Properties）」，新增以下兩筆並儲存：

| 屬性名稱（照抄） | 值（自己填） |
| --- | --- |
| `BOOTSTRAP_OWNER_PASSWORD` | 主管理人的密碼，至少 16 個字元 |
| `BOOTSTRAP_MANAGER_PASSWORD` | 共同管理人的**另一組**密碼，至少 16 個字元 |

建議用密碼管理器產生並保存兩組不同的密碼。不要把密碼填在 GitHub、README、程式碼或給 Agent 的訊息裡。系統的登入帳號固定為 `owner` 和 `coadmin`；首次成功登入後，初始密碼會轉成加鹽雜湊保存，這兩個初始密碼屬性會自動刪除。之後可在網站的「帳號設定」變更密碼。

### 2. 發布成自己的網站

在 Apps Script 右上角按 **部署 → 新增部署作業**，類型選 **網頁應用程式**。設定「**執行身分：我**」、「**誰可以存取：所有人**」，再按「部署」。Google 如要求授權，請用你自己的帳號閱讀權限並完成。複製部署畫面提供的網站網址，打開後以 `owner` 和第一組密碼登入。第一次登入會在你的 Google Drive 建立新的帳本試算表與備份資料夾；接著用 `coadmin` 和第二組密碼確認也能登入。

「所有人」代表有網址的人都能開啟**登入頁**；帳務讀寫仍要通過系統帳密。請只把網址和帳密交給你信任的管理人。若你的 Google Workspace 管理員限制對外部署，實際可用的選項可能不同。部署步驟可參考 [Google 的網頁應用程式說明](https://developers.google.com/apps-script/guides/web)。

### 3. 用虛構資料先試一次

先登錄一筆虛構收入、一筆虛構支出，讓另一帳號覆核支出，再查看餘額、報表與備份。準備匯入舊帳時，先核對原帳本的收入總額、支出總額和期末餘額；三者一致後再正式使用。

## 常見卡關

- **畫面顯示「尚未設定初始帳號」**：回專案設定，核對上表兩個屬性名稱、密碼長度與是否按了儲存。
- **Clasp 顯示 Script API not enabled**：到 [Apps Script 使用者設定](https://script.google.com/home/usersettings) 開啟 API，再請 Agent 重試。
- **網站仍是舊畫面**：修改或推送程式後，需到「部署 → 管理部署作業」將現有部署更新為新版本；單純儲存或推送不會更新正式網站。
- **複製貼上後找不到 `Index.html`**：新增 HTML 檔時名稱填 `Index` 即可；檔案清單會顯示 `Index.html`。

## 開發者與資料保護

`src/` 是原始碼，`scripts/build.js` 會產生 `dist/`（Clasp 推送用）和 `install/`（手動貼上用）。`npm run check` 執行測試、建置與語法檢查。更詳細的需求與驗收見[開發計畫](docs/需求與開發計畫.md)。農曆換算使用 MIT 授權的 `lunar-javascript`，建置檔保留其授權文字。

交易可能包含姓名、用途與憑證。公開程式不代表公開實際帳本；不要把試算表、憑證、舊帳 CSV、備份 JSON、密碼或測試截圖提交到 GitHub。每日備份位於部署者的 Google Drive，請定期另存獨立備份並練習還原。
