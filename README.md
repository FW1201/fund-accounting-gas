# 基金帳務管理系統

以 Google Apps Script 與 Google 試算表建置的雙人基金收支管理範本。介面支援手機與桌面，提供收支登錄、分類儀表板、A4 報表、匯入、雙人覆核、對帳、預算、結帳與備份。此公開專案只包含程式與虛構範例，不含任何既有帳本、帳號密碼、憑證、專案 ID 或部署網址。

## 功能

- 收入、支出、整數分金額、國曆與農曆日期；收入和支出皆有分類下拉選單。
- 期間餘額、收入與支出趨勢、分類圖表；儀表板可下載 CSV 或列印 PDF。
- 日期、類型、分類、關鍵字查詢；更正、作廢須填原因並留下前後操作紀錄。
- 現金與銀行帳戶、帳戶間轉帳、逐帳戶對帳、一般及指定用途基金、成員繳款與支出預算。
- 支出須由另一位管理人覆核；可附 PDF、JPG、PNG 憑證。結帳要求無待覆核支出與零差異對帳。
- 舊帳 CSV 或試算表匯入須先預覽、檢查重複並核對期末餘額；支援每日備份與備份驗證。

支出分類為「活動物資、關懷與協助、禮品、餐飲、補貼、其他」，收入分類為「成員繳款、捐款、活動收入、利息／回饋、其他收入」。分類碼從公開版開始採用通用值；既有舊版資料若使用不同分類碼，須先匯出並做欄位對照，不應直接覆寫舊部署。

## 安裝自己的系統

1. 安裝 Node.js 20 以上，執行 `npm ci`、`npm run check`。建置輸出在 `dist/`。
2. 新建**自己的** Google Apps Script 專案，啟用 Apps Script API，使用 Clasp 登入。將 `dist/Code.gs`、`dist/Index.html`、`dist/appsscript.json` 上傳至該專案；不要將本機 `.clasp.json` 加入版控。
3. 在 Apps Script「專案設定 → 指令碼屬性」設定 `BOOTSTRAP_OWNER_PASSWORD` 和 `BOOTSTRAP_MANAGER_PASSWORD`。兩組密碼各需 16–128 字元，請使用不同的隨機密碼，並保存在自己的密碼管理器。不要把密碼寫入程式或 GitHub。
4. 將網頁應用程式部署為「執行身分：我」、「存取權：所有人」。先以 `owner` 和第一組密碼登入；系統會建立新的試算表及備份資料夾。再以 `coadmin` 和第二組密碼驗證登入。首次登入時密碼轉成加鹽雜湊，初始密碼屬性隨即刪除。
5. 以虛構資料做一筆收入與支出，檢查另一帳號覆核、對帳、報表與備份，再匯入正式資料。核對原帳本的總收入、總支出與期末餘額後才正式使用。

注意：部署為「所有人」代表任何持有網址者都能開啟登入頁；只有通過應用程式登入的帳號可讀取帳務資料。請妥善保管網址和密碼。此帳密機制是小型團體的簡易登入，資料擁有者仍可直接修改自己的 Google 試算表與 Script Properties。

## 開發與測試

`npm run check` 會執行自動測試、建置與語法檢查。來源位於 `src/`，建置腳本在 `scripts/build.js`。`dist/` 為本機產物，不納入公開版控。需求與驗收見 [開發計畫](docs/需求與開發計畫.md)。本專案含 MIT 授權的 `lunar-javascript`，建置時會將其授權文字一併放入 Apps Script 程式碼。

## 資料保護與備份

交易可能包含姓名、對象、用途與憑證。公開原始碼與公開實際帳本是不同的事：不要將試算表、憑證、CSV 匯入檔、備份 JSON、密碼或測試截圖提交到 GitHub。每日備份在部署者 Google Drive；另需定期將試算表和憑證資料夾下載到獨立位置，演練還原並核對筆數與餘額。分享報表前請確認接收對象。
